# mann_spatial_learning

This is the repository for the paper "Unifying spatial and episodic representations in the hippocampus through flexible memory use". 

To generate the data, please navigate to the folder "experiments" and run the corresponding "*training" script for each experiment. To analyze the data, please run the corresponding "*plot" script in each subfolder after all data are generated. 

For the auto- and hetero-associative memory tasks, external datasets are used and can be downloaded here: https://www.kaggle.com/datasets/crawford/emnist. Please download the dataset and put it under the main directory.
